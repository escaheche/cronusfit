# Product Summary

Cronus Fit is an automated catalog creation platform for a sportswear brand (hourglass logo, blue/gold identity). It automates the full workflow from parametric cutting pattern generation through mockup creation, approval workflows, print-ready file generation (DTF and sublimation), static web catalog publication, quote management, and social media content generation.

## Key Capabilities

- Parametric SVG cutting pattern generation with age-group-aware templates (children 2T–16, adults XS–6XL)
- Size grading engine with anatomical proportion adjustments per age group
- Mockup compositing (front/back views with design overlays)
- Admin approval workflow with audit trail
- Static exhibition website with bilingual support (Spanish default, English)
- Client quote request and tracking system
- DTF and sublimation print file generation at production quality
- Social media content auto-generation (Instagram, Facebook)
- Bidirectional WhatsApp communication via WAHA/n8n for mockup approvals and quotes
- Free Tier usage monitoring with automatic degradation

## Target Users

- **Admin**: Business owner who manages patterns, approves mockups, publishes products, and handles quotes
- **Client**: External visitor who browses the catalog, requests quotes, and responds via WhatsApp or web

## Business Constraints

- Zero infrastructure budget — all AWS services must stay within Free Tier limits
- Communication is WhatsApp-first for client interaction
- All publication is manually controlled by Admin (no auto-publish)
- Platform language: Spanish primary, English secondary
